About

Building robotics systems that work end to end

My project work centers on the full stack of autonomous behavior: state estimation, motion planning, control, perception, and interaction design. I like systems problems where success depends on both algorithm quality and reliable integration.

Across these repositories, I repeatedly focus on one theme: making robots act more intelligently in the real world, whether that means navigating a map, following a person, learning from human takeover, or selecting safer and more comfortable handover behaviors.

Selected Work

Projects drawn from my repository portfolio

Featured System

MuSHR Autonomous Driving Stack

Built a closed-loop autonomy pipeline for an Ackermann-steered car using particle-filter localization, roadmap planning with Lazy A*, and vehicle-aware path tracking through PID, Pure Pursuit, and MPC.

  • Localization
  • Planning
  • Control
  • Systems Integration

Human-Robot Interaction

BuddyBot Human-Following Robot

Combined YOLO person tracking, MediaPipe pose estimation, action classification, and an FSM controller to drive service-oriented follow, approach, retreat, and platform-adjustment behaviors.

  • YOLO
  • MediaPipe
  • ROS 2
  • FSM

Robot Learning

Selective DAgger with Human Takeover Signals

Improved a MetaWorld push policy by treating human takeover moments as signals of risky states, then using a trained predictor to trigger selective expert relabeling during DAgger.

  • Imitation Learning
  • Vision Policy
  • Human-in-the-Loop

Research Direction

Structured Reward Modeling for Handover

Reframed robot handover as a human-preference problem by scoring candidate behaviors with structured reward functions that enforce safety gates while optimizing comfort.

  • Reward Modeling
  • Safety
  • Preference Learning

Mobile Robotics

TurtleBot Mapping and Navigation

Created maps, localized the robot, and evaluated navigation with multiple planner settings in ROS 2, connecting SLAM outputs to autonomous goal-directed behavior.

Developer Tooling

Map Annotation and Goal Interface
