Lab 6: Saving and Sending Navigation Goals

This project focuses on building a custom ROS 2 interface for saving named poses in the map, reloading them across runs, and sending navigation goals by semantic name.

Open Source README

Main Features

  • List, save, overwrite, delete, and navigate to named poses
  • Persist pose data in CSV format
  • Publish pose arrays for visualization
  • Render saved goals as Rviz markers

Map Annotator Node

Terminal-driven pose management

commands:
- list
- save <name>
- delete <name>
- goto <name>
- exit
- help

The main node stores pose name, position, and orientation in the map frame, publishes those poses continuously as a `PoseArray`, and saves them to CSV when the session exits.

Visualization

Rviz markers as a lightweight robotics UI

A second node subscribes to the pose array and publishes markers or marker arrays into Rviz so that the user can see saved navigation targets directly in the map frame.

Why It Matters

Bridging robot spatial memory and user semantics

This project moves beyond raw coordinates by letting the user work with meaningful names such as rooms or objects. It is a small but important step toward usable robot interfaces and task-level autonomy.
