Research Direction

Structured Reward Modeling for Complex Human-Robot Handover

This project reframes handover from a pure motion-planning problem into a human-preference-centered reward modeling problem. The goal is to score, explain, and rerank candidate handover behaviors.

Open Source README

Main Principle

  • Safety is a gate, not just another weighted feature
  • Comfort is optimized only after safety clears the threshold
  • The model is designed for candidate reranking, not direct end-to-end control

Problem Reframing

From pairwise preference to candidate-set selection

The real system is not simply choosing between trajectory A and B. It takes a full interaction context, generates a candidate set of locally feasible handover behaviors, and then uses structured reward to rerank and select the most acceptable option.

Inputs

Human state, hand location, body orientation, robot initial state, local environment, obstacle summary, reachable region, task goal, and scenario type.

Candidate Generation

Multiple local candidates are produced in the same context, including classical, learned, hybrid, and safe-fallback behaviors.

Structured Supervision

The project predicts preference-related signals such as reasons, reactions, and better-choice judgments to support interpretable reward formation.

Reward Logic

The current V2 path focuses on two main axes: `safety` and `comfort`, with safety functioning as a veto-style gate rather than an equal additive term.

Core Formula

Safety Gates, Comfort Optimizes

structured_score = comfort_score - lambda_veto * ReLU(tau_safe - safety_score)^2

This expresses the intended human judgment logic: a handover does not become acceptable simply because it is comfortable if it already feels unsafe.
