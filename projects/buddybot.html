Human-Robot Interaction

TurtleBot3 Human-Following Robot

BuddyBot combines YOLO tracking, MediaPipe pose estimation, action classification, and an FSM-based behavior layer to create a service robot that follows people and reacts to their intent.

Open Source README

Pipeline

  • YOLO detects and tracks the main person
  • MediaPipe extracts 33 body keypoints
  • A trained classifier predicts actions such as wave, reach, sit, stand, and walk
  • An FSM converts those signals into robot motion and platform-height behavior

System Goal

Tracking is not enough without interaction logic

The robot is designed for service interaction rather than generic following. It must respond differently when a user waves, walks, sits, reaches out, or stands up again. That makes behavior understanding just as important as person detection.

YOLO Tracking

The largest person bounding box is selected as the interaction target. Box center controls heading, and box size is used as a rough distance signal for forward, stop, and retreat logic.

Pose-Based Action Recognition

MediaPipe Pose converts each frame into a 66-dimensional keypoint vector. That feature vector feeds the trained action classifier, reducing sensitivity to background clutter and lighting noise.

FSM Behaviors

States such as `IDLE`, `FOLLOW`, `APPROACH_60`, `APPROACH_30`, `APPROACH_20`, and `RETREAT_60` encode service behavior based on both detected action and current person distance.

Platform Adjustment

A separate controller maps predicted posture to a height-adjustable platform so that a seated or standing user can interact with the robot more comfortably.

Online Runtime

Live execution chain

camera -> YOLO / MediaPipe -> action classifier -> FSM -> /cmd_vel + platform control

The deployed system is composed of multiple ROS 2 nodes, including a tracker, a human action publisher, the main follower FSM, and the platform height controller.
