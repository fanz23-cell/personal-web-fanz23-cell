Mobile Robotics

Lab 5: Mapping and Navigation

This project explores map creation, localization, and navigation on TurtleBot, connecting SLAM, map-based navigation, and planner comparison into one practical workflow.

Open Source README

Learning Objectives

  • Create 2D environment maps
  • Use maps for autonomous navigation
  • Build intuition for navigation algorithms and planner choices

Workflow

From mapping to navigation evaluation

  1. Run SLAM in the maze world and explore until the environment is mapped.
  2. Save the map into a `maps` folder for later reuse.
  3. Restart the system using the saved map and navigation stack.
  4. Estimate the robot pose on the map and send navigation goals.
  5. Compare planning behavior using both Dijkstra and A* on the real maze.

Deliverables

What the project demonstrates

Mapping

Producing a reusable maze map and understanding how environment exploration supports later navigation.

Localization

Using pose estimation tools to align the robot with the saved map before goal-directed movement.

Planner Comparison

Switching configuration to compare Dijkstra and A* behavior instead of treating navigation as a black box.

Real Robot Transfer

Extending the same workflow from simulation into the physical robot and real maze setup.
