# Personal Web

This repository contains a personal website for **Fan Zhang**, designed for job search, portfolio presentation, and graduate or research applications.

The website highlights:

- robotics and embodied AI interests
- selected project experience
- technical strengths
- a professional contact section linked to LinkedIn

## Files

- `index.html` - main website page
- `styles.css` - styling and responsive layout
- `script.js` - small scroll and reveal interactions
- `README(1).md` to `README(6).md` - source project summaries used to build portfolio content

## How to Run

This is a static website, so no build step is required.

Option 1:

1. Open `index.html` directly in a browser.

Option 2:

1. Start a simple local server in this folder:

```bash
python3 -m http.server 8000
```

2. Open `http://localhost:8000` in your browser.
